Tet4D tutorials

  1. Gluing Edges and Recognizing Topological Surfaces — a self-contained introduction to 2D edge identifications, square symmetries, quotient invariants, and Python verification. Companion pages: six square gluings built step by step, and interactive gluing viewers.

  2. Curvature, Seam Traversal, and Mercator Maps — Gaussian curvature, Gauss–Bonnet, piecewise-flat cone singularities, parallel transport, cartographic distortion, and Python checks.

  3. Can you come home mirrored? — compare position, transported frames, and piece adjacency across three square gluings. Files and how to run them: README.

Get the repository checkout and open learning/tutorials/curvature-seams-and-mercator/interactive-earth/index.html in a browser. Keep the adjacent JavaScript, CSS and generated land mask together. The HTML link on GitHub shows the source. See the demo guide and dataset attribution.

Tutorial scripts are educational standalone programs. They do not modify the game engine, native topology resolver, or runtime contracts.
