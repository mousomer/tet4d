Embed Tet4D Learning

Host the contents of this release folder together. Paste a script tag into your page at the point where the tutorial should appear.

Full learning pack

<script src="/tet4d-learning/tet4d-learning.js" defer></script>

Lesson 03 domino tutorial

<script src="/tet4d-learning/tet4d-learning.js"
        data-view="domino" data-height="900" defer></script>

Replace /tet4d-learning/ with the folder URL on your host. The script loads the tutorial from that same folder. Set data-height in pixels to adjust the height.

WordPress and other page builders

Put the snippet in a Custom HTML block that allows scripts. If your editor allows frames, you can use this HTML-only embed:

<iframe src="/tet4d-learning/index.html" title="Tet4D Learning"
        width="100%" height="850" style="border:0"></iframe>

If your editor removes both elements, link to the hosted index.html from the page. Visitors need access to the host serving the release.
