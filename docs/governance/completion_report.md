# Completion Report

Use this report when handing off a completed change or pull request. Report
facts and evidence; distinguish implemented, automatically verified, manually
inspected, human accepted, and merged states.

## Summary

State the outcome and whether every acceptance criterion was satisfied.

## Files Changed

List changed files or grouped path families and the purpose of each group.

## Semantic Impact

State changed and deliberately unchanged behavior, schemas, deterministic
identity, and compatibility.

## Authority Changes

Name any authority transfer or routing change. Write `None` when ownership did
not change.

## Tests and Verification

List exact commands and results. Separate failures, skips, and advisories.

## Manual Checks

Record the environment and result, or state that none applied.

## Known Warnings

Separate newly introduced warnings from pre-existing accepted advisories.

## Unresolved Limitations

List blockers, unverified areas, risks, and explicit deferrals.

## Diffstat

Provide the concise diffstat; do not paste a full unified diff.

## Commit SHA

Report the commit tested and published.

## PR URL

Report the pull request URL and its state.

## Worktree State

Report branch, target-base agreement, and whether the tracked tree is clean.
