# Bounded manifest repairs

Objective: improve instruction correctness and engineering outcomes through the existing dispatch, manifest, test and handoff mechanisms. No telemetry platform, blanket pack rollout, new statistical policy, publishing or dependency/environment migration.

## Frozen acceptance and compatibility

`docs/experiments/governance_repair_acceptance_2026_10.json` freezes discovered cases before rule edits. These are acceptance regressions, not independent holdouts or observed agent-behavior tests. Existing representative resolution remains a bounded convenience: the human compositional routing authority decides complete context from runtime requirements and actual file ownership. No generic prompt classifier or shared pack schema change is introduced.

Acceptance: moderate Godot work receives Godot guidance; Python-only work retains Python; Godot/shared-contract work preserves all provider/consumer routes; named Godot ownership cannot be hidden by Python-only wording. Explicit runtime/path contracts override task-size labels; multiple real surfaces require the union. Authority and direct source reads remain necessary for ambiguous work.

External repairs preserve current dirty files through fresh preimages: reconcile Raizor's environment documentation/runner without modifying environments; close Gifted historical fences outside managed instructions; add minimal Depth/Bird entry points referencing existing specifications. Do not modify original audit artifacts, raw data or historical results.

Delegation stays optional. Existing prompts/transcripts/handoffs record supplied constraints, contracts, source identity, validation and access limits; supplied or inherited context is evidence of availability, never understanding or compliance.

## Verification boundary

Focused routing and structural cases, a scanner traversal regression and applicable mandatory gates establish only their actual boundaries. A scanner timeout is a failure. Its cause was file volume, not load: 45,616 candidates against 1,681 tracked files, 20,445 of them in nested `.claude/worktrees` and 20,944 in scratch folders leaked by two generator tests; those tests now use `tmp_path`. Scientific runners that overwrite historical results require isolated outputs before execution; record any unavailable or unsafe full checks. Current inherited instructions and product authorities retain force.

## Outcome comparison (follow-up, not a completion prerequisite)

Freeze a small matched set of one UI requirement, one scientific evidence-summary task and one provider/consumer change before running either condition. Use identical source snapshots, model versions, budgets, tools, environments and acceptance reviewers; vary only the reviewed instruction/routing repair. Keep discovered regression cases separate from independently selected holdouts. Primary measures: externally reviewed defects, regressions, authority/contract mistakes and technical debt introduced or left unresolved. Secondary: routing, retries, effort, wall time, cost and injected/read instruction burden. Preserve failed runs and missing evidence. A smaller manifest or higher access/check rate cannot offset worse primary outcomes. No experiment has been executed or outcome benefit established by this repair.
